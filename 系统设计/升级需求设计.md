# 3. 核心业务流程（重点）

## 3.1 记账流程（关键链路）

```
用户新增交易   ↓写入交易表   ↓（事务）更新账户余额   ↓发布事件 transaction.created   ↓预算模块消费更新   ↓触发预算预警
```

👉 这是你系统**最核心的业务链路（答辩重点）**

---

## 3.2 预算执行流程

```
交易发生   ↓匹配预算（分类/账户）   ↓更新已消费金额   ↓计算使用比例   ↓判断是否超阈值   ↓发送预警（WebSocket）
```

---

## 3.3 导入+去重流程

```
上传文件（CSV/Excel）   ↓解析数据   ↓模糊匹配（描述 + 金额 + 时间）   ↓Levenshtein距离计算   ↓去重过滤   ↓批量写入
```

# 4.2 账户模块

- 查询账户

## 数据结构


---

# 4.3 交易模块（最重要）

## 功能点

- CRUD交易
- 批量导入
- 筛选/分页

## 数据结构

```
{  "id": "uuid",  "account_id": "uuid",  "category_id": "uuid",  "type": "income/expense/transfer",  "amount": 100.50,  "description": "午餐",  "transaction_time": "timestamp"}
```

---

## 关键规则（非常重要）

### 1️⃣ 余额更新规则

```
收入 → +balance支出 → -balance转账 → A减少 B增加
```

---

### 2️⃣ 去重规则

匹配条件：

- 金额相同 ±1%
- 时间窗口 ±5分钟
- 描述相似度 > 80%

---

# 4.4 预算模块（智能核心）

## 数据结构

```
{  "id": "uuid",  "user_id": "uuid",  "category_id": "uuid",  "amount": 2000,  "period": "monthly",  "alert_threshold": 0.8,  "spent": 1200}
```

---

## 关键逻辑

### 使用率计算

```
usage = spent / amount
```

### 预警规则

|条件|动作|
|---|---|
|>80%|黄色预警|
|>100%|红色预警|

---

## 预测逻辑（加分点）

- 滑动窗口（最近7/30天）
- 预测本周期总消费
